# S7 · 验收收口（人）

## 目标
把卡真正关掉。**这一步只有人能做。**

## 谁来做
看板的「完成」按钮 / 人点。评审门（`review_state === 'approved'`）或显式 `skipReview` 才放行。

## 判据
- `in_review → done`；
- `governance_audit` 里 `actor=human`；
- 卡上有 S5 的证据评论（没有证据就被收口，说明流程漏了一步）。

## 失败处置
| 错误码 / 现象 | 处置 |
| --- | --- |
| `REVIEW_NOT_APPROVED` | 评审没通过 ⇒ 先过评审；确需跳过评审，必须**人**显式 `skipReview: true`（会落 `review_skipped` 审计） |
| `GOVERNANCE_AGENT_DONE` | 执行侧/agent 在写 `done` ⇒ 停手，交人 |
| `HUMAN_REVIEW_CANNOT_DONE` | 人工校验任务不得置完成 ⇒ 用人工结论入口（continue / change-requirement / close） |

## 别做的事
- 不要"先 done 再补证据" —— 证据是收口的前置，不是事后装饰。
- 不要代替人点完成：这是本仓最硬的一条红线。
